# Disaster Damage Assessment and Change Detection

This project focuses on assessing disaster damage and implementing change detection techniques. This documentation outlines the project's folder structure and its purpose.

## Folder Structure

### `data/`
- `raw/`: Contains raw data files.
- `processed/`: Contains processed data files.
- `annotations/`: Holds annotation files for the dataset.

### `models/`
- This directory is intended for storing machine learning models and their parameters.

### `backend/`
- Contains server-side code and APIs related to the project.

### `frontend/`
- Stores all the client-side code for the project’s user interface.

### `annotation_tool/`
- Includes tools and scripts for annotating data.

### `utils/`
- Contains utility functions and modules to support the main project logic.

### `docs/`
- Documentation files and project guidelines.

### `logs/`
- Log files for tracking project execution and performance.
